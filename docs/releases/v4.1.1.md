# vue3-next-qrcode v4.1.1

`v4.1.1` is a backward-compatible hotfix for the `v4.1.0` release. It does not
remove or rename any public API.

## Release Blockers Fixed

- Vite 8 now uses its default Oxc minifier. A clean Node 24 / pnpm 11.9.0 build
  no longer depends on an undeclared ancestor `esbuild` installation.
- GIF input is bounded before LZW decompression: 20 MiB encoded bytes, 300
  frames, 2048x2048 dimensions, and 16M decoded frame pixels. Shared caching is
  limited to 20 entries and 64 MiB, and network/image work has a 30 second
  timeout with abort propagation.

## Compatibility Fixes

- `dotScale` only overrides component-specific scales when explicitly set.
- All CSS export paths include declaration entries for strict TypeScript side
  effect imports.
- GIF disposal type 2 restores the logical-screen background color, or clears
  to transparent when the color is unavailable.
- Component and composable rendering share `version`, `maskPattern`,
  `correctLevel`, and `dotScale` validation.
- The root package exports `QRErrorCorrectLevel` with the canonical mapping
  `L=1`, `M=0`, `Q=3`, and `H=2`.
- Error controls use native button semantics, GIF downloads infer `.gif`, and a
  disposed composable cannot return to an `idle` state through `reset()`.

## Release Integrity Notes

- The npm `4.0.0` artifact reports
  `gitHead=2b61a170796b99e0468820b9a7a689fc889ff899`. The existing public
  `v4.0.0` tag incorrectly points to the `3.1.0` commit and is intentionally not
  rewritten by this hotfix.
- `v4.1.0` documented public compatibility changes under a minor version.
  `v4.1.1` contains fixes only; future breaking changes require a major release.

## Required Gates

- Clean Node 24 and pnpm 11.9.0 `pnpm install --frozen-lockfile` followed by
  `pnpm run test`.
- Production dependency audit and publish dry-run.
- Candidate tarball verification with Vue 3.0.1 / TypeScript 4.1.6, Vue 3.5.41
  / TypeScript 6 strict CSS imports, and Nuxt 4.5.2 SSR/hydration.
- GitHub CI must pass on the exact candidate commit before tagging or npm
  publication.
